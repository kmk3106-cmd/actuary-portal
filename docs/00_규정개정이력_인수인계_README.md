# 규정 개정이력 관리 — 계리포탈 인수인계

계리결산팀 운영관리포탈(portal.kkuks.com)에 **규정 개정이력 관리 기능**을 붙이기 위한 인수인계 묶음이다.

---

## 1. 무엇을 넘기는가

두 가지다.

| 구분 | 내용 | 해당 문서 |
|---|---|---|
| ① 보고서 서식 | 신구조문 대비 리포트를 같은 모양으로 계속 찍어내기 위한 규칙 | `docs/01_리포트_스타일가이드.md` |
| ② 신규 기능 | 개정 시기별 목록 · 상세 열람 · 자동 수집 페이지 명세 | `docs/02_규정개정이력_구축지시서.md` |

②가 본 과제이고, ①은 ②가 보여줄 리포트를 만드는 방법이다.

---

## 2. 파일 구성

```
계리포탈_규정이력_인수인계/
├ README.md                                  ← 지금 읽는 문서
├ docs/
│  ├ 01_리포트_스타일가이드.md                 ← 서식 토큰 · 컴포넌트 · 포탈 적재 방법
│  └ 02_규정개정이력_구축지시서.md             ← 신규 페이지 구축 지시서 (본 과제)
├ templates/
│  └ report-template.html                    ← 빈 골격 · 복사해서 쓴다
└ samples/
   └ 계리가정_세칙개정_대비_포탈용.html         ← 완성 예시 1건 · 그대로 적재 가능
```

---

## 3. 읽는 순서

```
1  README.md                       전체 그림
2  samples/…_포탈용.html            브라우저로 열어서 결과물 확인
3  docs/02_…구축지시서.md            만들 것 · 본 과제
4  docs/01_…스타일가이드.md          리포트 찍을 때 참고
```

구축 작업만 할 것이라면 **2 → 3** 만 보면 된다.

---

## 4. 지금 포탈 현황

2026년 10월 18일 `kb-sop.html` 실기동 확인 결과다.

### 이미 있는 것

| 항목 | 내용 |
|---|---|
| 페이지 | `kb-sop.html` — 3단 구성 · 카테고리 / 문서목록 / 본문 |
| 카테고리 | `kbc_regulation` **규정·기준** 이 이미 존재 |
| 문서 적재 | 전체 HTML을 `<iframe srcdoc>` 으로 품는 방식이 이미 동작 중 |
| 공통 JS | `js/portal.js` · `js/rbac.js` · `js/auth.js` |
| 권한 | 팀장 / 팀원 역할 구분 동작 |

### 없는 것

- 개정 **시기별** 목록과 상태 추적
- 공포일 · 시행일 · 의견제출 시한 같은 **일정 필드**
- 외부 공고를 **자동으로 가져오는** 경로
- 개정 건과 리포트 문서의 **연결**

→ 이 네 가지를 채우는 것이 본 과제다.

## 5. 첫 작업

`samples/계리가정_세칙개정_대비_포탈용.html` 1건을 **기존 kb-sop.html에 수동 적재**해 본다.
적재 방법은 `docs/01_리포트_스타일가이드.md` 5장에 있다.

이것이 되면 신규 페이지가 보여줄 리포트의 모양과 적재 경로가 검증된 것이다. 그 다음 `docs/02` 로 넘어간다.
