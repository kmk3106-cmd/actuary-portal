# 01. 리포트 스타일 가이드

계리 보고서를 **같은 모양으로 계속 찍어내기 위한** 규칙이다.
신구조문 대비 리포트뿐 아니라 TVOG 변동분석 같은 다른 계리 보고서도 이 서식을 쓴다.

기준 파일 — `templates/report-template.html` · `samples/계리가정_세칙개정_대비_포탈용.html`

---

## 1. 기본 전제

### 1-1. 지켜야 하는 것

| 항목 | 규칙 |
|---|---|
| 글꼴 | `IBM Plex Sans KR` · Google Fonts 에서 로드 |
| 강조색 | 빨강 `#c8102e` 한 가지 |
| 가로 스크롤 | **절대 금지** · 표가 넓으면 글씨와 여백을 줄여 화면에 맞춘다 |
| 소제목 번호 | 장 번호를 딴 일련번호 필수 — `2-1` `2-2` |
| 제목 괄호 | 제목에 괄호 금지 · 용어 설명은 본문 첫 문장에서 한 번 |
| 다크 모드 | 토큰으로 정의 · 하드코딩 색상 금지 |

### 1-2. 색상 토큰

모든 색은 `:root` 에서 토큰으로 선언하고, 컴포넌트는 토큰만 쓴다.

```css
--bg    배경        --fg    본문 글씨
--sub   보조 글씨    --line  가는 선
--acc   강조 빨강    --grid  표 머리글 배경
--ok    초록        --src   근거 쪽글씨 파랑
```

다크 모드는 같은 토큰을 세 곳에서 재정의한다. 이 구조를 깨면 한쪽 테마에서 글씨가 안 보인다.

```css
:root { … }                                                   /* 밝은 테마 */
@media(prefers-color-scheme:dark){ :root:not([data-theme="light"]){ … } }
:root[data-theme="dark"]{ … }
```

### 1-3. 글씨 크기 토큰

```css
--fs   본문 15px      --fst  표 16px
--fsh  표 머리글 12.5px    --pad  좌우 여백 20px
```

화면이 좁아지면 `@media` 에서 토큰만 줄인다. 개별 컴포넌트에 크기를 직접 쓰지 않는다.

```
≤700px   --fs 14.5  --fst 14.5  --fsh 11.5  --pad 16
≤430px   --fst 13   --fsh 11
```

## 2. 문서 골격

```html
<div class="wrap">
  <div class="top">     머리말 — 배지 · 제목 · 부제
  <div class="nav">     목차 — 상단 고정
  <div class="sec">     본문
    <h2 id="c">결론</h2>
    <p class="lead">    한 문장 요약
    …
    <h2 id="a">부록</h2>
    <details>           접었다 펴는 영역
</div>
```

### 2-1. 장 구성

```
결론        한 문장 요약 → 요약표 → 산문 → 집계
1장         전제 · 개요
2장 …       본론 · 소제목은 2-1, 2-2
마지막 장    조치 사항
부록        details 아코디언
```

### 2-2. 서술 원칙

**앞 표에 나온 합계·증감 숫자를 먼저 받아 문장을 시작한다.** 처음 보는 숫자부터 꺼내지 않는다.

```
X   적립금 변동 효과가 △35,262원에 그친 반면 …
O   5월에서 6월 증감 586,352원은 대부분 … 에서 비롯되었다.
    적립금 변동 효과는 △35,262원에 그친 반면 …
```

## 3. 컴포넌트 목록

### 3-1. 머리말

```html
<div class="top"><span class="tag">사전예고</span>
<h1>제목</h1>
<p class="subt">부제 · 근거 · 기간</p></div>
```

### 3-2. 요약 문장

```html
<p class="lead">한 문장으로 끝나는 결론</p>
```

### 3-3. 표

| 클래스 | 용도 | 글씨 |
|---|---|---|
| `table.mid` | 5열 안팎 일반 표 | 기본의 90% |
| `table.tight` | 6열 이상 빽빽한 표 | 기본의 82% |
| `table.wrap-ok` `table.wrap-ok2` | 긴 문장이 들어가는 표 · 줄바꿈 허용 | 셀 0.9em |
| `table.act` | 조치 사항 전용 · 제목+설명 2단 | 15px |

셀 클래스

```
td.l    왼쪽 정렬 · 행 이름
td.r    오른쪽 정렬 · 숫자 · tabular-nums
tr.hl   강조 행
tr.sub  소계 행
tr.tot  합계 행 · 아래 굵은 선
td.grp  세로 병합 그룹 머리
```

표는 항상 `<div class="tw">` 로 감싼다.

### 3-4. 근거 쪽글씨

“몇에서 몇으로” 바뀌었는지를 파란 쪽글씨로 단다.

```html
<span class="src">※ 변동성 연 14.63% → 15.64%</span>
```

### 3-5. 콜아웃

```html
<div class="callout">…</div>           빨간 선 · 주의
<div class="callout ok">…</div>        초록 선 · 확인됨
<div class="callout neutral">…</div>   검은 선 · 설명
```

### 3-6. 산식

```html
<div class="fml"><span class="nm">로그-선형 모형</span>
ln(해약률) = α + β × 경과기간
<span class="ps">α 절편 · β 기울기</span></div>
```

### 3-7. 현행 · 개정안 대비

신구조문 대비 리포트 전용이다.

```html
<h3>2-1. <span class="bdg n">신설</span>항목 제목</h3>
<div class="gist">한 줄 요지</div>
<div class="cmp">
  <div class="col col-a"><div class="cmph">현행</div><div class="law">
    <p>현행 조문 · 없어지는 문구는 <em>이렇게</em></p>
  </div></div>
  <div class="col col-b"><div class="cmph">개정안</div><div class="law">
    <p>개정 조문 · 새로 들어오는 문구는 <em>이렇게</em></p>
    <p class="ind">한 단계 들여쓰기</p>
  </div></div>
</div>
```

| 요소 | 뜻 |
|---|---|
| `.bdg.n` | 초록 배지 — 신설 |
| `.bdg.c` | 빨강 배지 — 변경 |
| `.bdg.m` | 회색 배지 — 이동 · 삭제 |
| `.col-a em` | 현행 칸 강조 — 빨간 형광펜 |
| `.col-b em` | 개정안 칸 강조 — 초록 형광펜 |

화면이 좁아지면 두 칸이 위아래로 쌓인다. 현행이 위, 개정안이 아래다.

### 3-8. 부록

```html
<details><summary>A. 제목</summary><div class="body">
  …
</div></details>
```

## 4. 신구조문 대비 리포트를 쓸 때

### 4-1. 점선을 되살린다

금감원 신구조문 대비표에서 개정안 칸의 `———————` 는 **현행과 같다**는 뜻이다.
이것 때문에 원문이 안 읽힌다. **점선 자리에 현행 문구를 채워 넣고 바뀐 부분만 형광펜을 친다.**

```
원문   ㉮ ------------------------ ----의 경과기간별 해약률 및 …
리포트 ㉮ 무·저해지상품의 경과기간별 해약률 및 … (바뀐 곳만 색칠)
```

### 4-2. 분류 기준

| 배지 | 쓰는 경우 |
|---|---|
| 신설 | 현행에 대응하는 자리가 없다 |
| 변경 | 현행 문구가 있고 내용이 달라진다 |
| 이동 | 자리만 옮기고 내용은 같다 |

### 4-3. 쉬운 말로 다시 쓴다

조문을 그대로 옮기지 말고, **신입사원이 처음 보는 자료라 치고** 요지를 한 줄 덧붙인다.

```
조문   납입완료 시점에 해약률이 "0.1%"로 수렴하는 로그-선형 모형을 사용하여 추정
덧말   한 해가 지날 때마다 해약률이 일정한 비율로 줄어든다는 뜻이다
```

## 5. 포탈에 적재하는 방법

### 5-1. 저장 구조

`kb_documents.content` 는 **HTML 문자열**이다. 기존 문서는 전체 HTML을 `iframe srcdoc` 으로 품는다.

```html
<div style="margin:0;"><iframe srcdoc="…escaped html…"
  style="width:100%;height:1200px;border:0;" ></iframe></div>
```

### 5-2. 감싸는 코드

리포트 HTML 파일을 그대로 넣으려면 따옴표를 치환해야 한다.

```js
function wrapForPortal(html, heightPx = 1400) {
  const esc = html
    .replace(/&/g,  '&amp;')
    .replace(/"/g,  '&quot;');
  return `<div style="margin:0;"><iframe srcdoc="${esc}" `
       + `style="width:100%;height:${heightPx}px;border:0;" `
       + `sandbox="allow-same-origin"></iframe></div>`;
}
```

> `sandbox` 에 `allow-scripts` 를 넣지 않는다. 리포트는 스크립트 없이 동작하도록 만든다.
> 계산기처럼 스크립트가 필요한 문서만 예외로 허용하고, 그 판단은 등록자가 한다.

### 5-3. 등록

기존 `kb-sop.html` 의 저장 로직을 그대로 쓴다. 새로 만들지 않는다.

```
category_id    kbc_regulation
title          규정명 + 개정 제목
content        wrapForPortal(리포트HTML)
is_published   true
```

### 5-4. 높이

`srcdoc` iframe 은 내용 높이를 자동으로 잡지 못한다. 세 가지 중 하나를 쓴다.

| 방법 | 설명 |
|---|---|
| 고정 높이 | 등록할 때 넉넉히 준다 · 가장 단순 |
| 등록 폼에서 지정 | 등록자가 숫자를 입력 |
| postMessage | 리포트 안에서 높이를 올려보내 부모가 받아 조정 — 스크립트 필요 |

처음에는 **고정 높이**로 간다.

## 6. 점검 항목

리포트를 만들고 나면 아래를 확인한다.

```
□ 1100px · 400px 두 폭에서 가로 스크롤이 없다
□ 밝은 테마 · 어두운 테마 모두 글씨가 읽힌다
□ 하드코딩 색상이 없다 — 토큰만 쓴다
□ 소제목에 장 번호가 붙어 있다
□ 표 안 숫자가 오른쪽 정렬이고 자릿수가 맞는다
□ 본문이 앞 표의 숫자를 받아 시작한다
□ 제목에 괄호가 없다
□ 결론만 읽어도 무엇이 바뀌는지 알 수 있다
```
